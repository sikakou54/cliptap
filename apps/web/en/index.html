FAQ

Frequently asked questions.

How much can I do for free?

Save up to 50 templates, 50 shortcuts (5 values each), 3 profiles and 5 custom variables for free. Keyboard insertion, all 7 system variables and 94 formats are included. Categories are unlimited.

How is a shortcut different from a template?

Templates hold sentences; shortcuts hold values. Save short values such as a name, a phone number or an address, and the keyboard inserts just the value. One shortcut can hold several values, and the list stays open after an insert, which suits filling a form's fields in order. A value can be masked on screen, but that only hides it from view — it is stored the same way as everything else on your device.

Where is my data stored?

Your templates, shortcuts, categories, profiles and variables are stored on your device in the mobile app, or in your browser in the web app. ClipTap does not store or sync that content on its servers.

Does it work offline?

Creating, searching, expanding variables, copying and typing with the keyboard all work offline. Only account linking, Pro entitlement checks, ads and store links need a network. The web app also needs a network to load the page itself.

Do I need to set anything up on iPhone?

You need to add the ClipTap keyboard in Settings. Full Access is required to record usage counts, but inserting text works without it.

Can I type normal text with the ClipTap keyboard?

No. The ClipTap keyboard is built for picking and inserting what you have already saved, so switch back to your usual keyboard to type. Inside it you can filter by category, re-sort four ways, switch profile temporarily and preview. Keyword search, and creating, editing or deleting templates, are done in the app.

Can I insert text with the keyboard on the web app?

No. Keyboard insertion is a feature of the iOS and Android apps. The web app is where you organise, edit and copy your templates and shortcuts in a browser; it starts by loading a .cliptap file, it does not sync with your phone automatically, and you export a file to save your changes.

Can I move my data to a new phone?

Export a .cliptap file and import it on the new device. Passwords are matched and a checksum is verified, but the file contents are not encrypted.

What happens if I cancel Pro?

You keep Pro until the end of the billing period. Profiles and custom variables above the free limits are not deleted — they are just disabled, and they come back if you resubscribe. Templates and shortcuts are never disabled and stay usable even above the free limits — you just can't add new ones beyond the limits.
