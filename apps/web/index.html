SYSTEM VARIABLES

自動で入る。

毎回変わるところはシステム変数にしておくだけ。入力したその瞬間の日付・時刻・曜日に置き換わります。変数は7種、書式は94種から選べます。

CUSTOM VARIABLES

会社名や宛名も、
一度登録するだけ。

会社名・担当者名・署名はカスタム変数に。相手や仕事ごとに「プロファイル」を切り替えれば、同じ定型文がそのまま別の相手向けになります。

SHORTCUTS

電話番号も住所も、
打たずに選ぶ。

氏名・電話番号・請求先・住所のように、文章ではない短い値はショートカットへ。キーボードで名前を選ぶと、画面が切り替わらずその下に値の行が開き、タップした値だけが入力欄に入ります。

値を入れても行は開いたままなので、申し込みフォームの項目を上から順に埋めていけます。見せたくない値は画面上で伏せて表示でき、入力されるのは実際の値です。プロファイルごとに登録でき、変数も展開されます。

FAQ

よくある質問。

無料でどこまで使えますか？

カテゴリは無制限、拡張キーボードは件数上限なし、システム変数7種と94書式もすべて無料です。定型文は50件、ショートカットは50件（1つにつき値5件）まで登録でき、プロファイルは3件、カスタム変数は5件まで無料で使えます。

ショートカットは定型文と何が違いますか？

定型文は文章、ショートカットは値です。氏名・電話番号・住所のような短い値を登録しておくと、キーボードから値だけを入力欄に入れられます。1件のショートカットに複数の値を持たせられ、値を入れても一覧は開いたままなので、フォームの項目を上から順に埋めるときに向いています。値は画面上で伏せて表示できますが、これは表示を隠すだけで、端末内での保存のしかたは他のデータと同じです。

データはどこに保存されますか？

定型文・カテゴリ・プロファイル・変数はすべて端末内に保存されます。クラウドには保存されず、定型文の中身が外部へ送られることもありません。

オフラインでも使えますか？

定型文の作成・検索・変数展開・コピー・キーボード入力はオフラインで完結します。アカウント連携・Pro権利の確認・広告・ストア遷移だけネットワークが必要です。Web版はページの読み込みにネットワークが必要です。

iPhoneで使うには設定が必要ですか？

「設定」からClipTapキーボードの追加が必要です。使用回数の記録にはフルアクセスの許可が必要ですが、定型文の入力そのものはフルアクセスなしでも行えます。

ClipTapのキーボードで普通の文字も打てますか？

打てません。ClipTapのキーボードは、登録した定型文とショートカットを選んで入れることに特化しています。文字を打つときは、お使いのキーボードへ切り替えてください。キーボードの中では、カテゴリでの絞り込み、4種類の並べ替え、プロファイルの一時的な切り替え、プレビューができます。文字での検索と、定型文の作成・編集・削除はアプリ側で行います。

Web版でもキーボードから入力できますか？

できません。キーボードからの入力はiOS・Androidアプリの機能です。Web版はブラウザで定型文とショートカットを整理・編集し、コピーするための画面で、はじめに.cliptapファイルの読み込みが必要です。モバイルとの自動同期はなく、編集した内容は書き出して保存します。

機種変更のときデータを移せますか？

.cliptapファイルで書き出して、新しい端末で読み込めます。パスワードの一致確認とチェックサム検証を行いますが、ファイルの内容は暗号化されません。

Proを解約するとどうなりますか？

契約期間の終わりまでProを使えます。上限を超えたプロファイル・カスタム変数は削除されず無効になるだけで、Proに戻せば再び使えます。定型文・ショートカットは無料プランの上限を超えていても無効にならずそのまま使え、上限を超える新規追加だけができなくなります。
