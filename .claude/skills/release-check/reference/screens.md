# 画面チェックリスト

`apps/mobile/app/` の全ルートを網羅する。各画面で「到達経路」「確認すること」「よくある壊れ方」を示す。
座標は端末サイズで変わるため書かない。スクリーンショットを読んで対象を探すこと。

チェック結果は「OK / NG / 未確認」で必ず3値で記録する。到達できなかった画面を暗黙にOK扱いしないこと。

---

## 1. 起動・ホーム

### 起動 → スプラッシュ → ホーム（`app/_layout.tsx`, `app/index.tsx`）
到達: `sim.sh launch`

確認:
- スプラッシュのアプリアイコンが表示される（画像アセットの解決が壊れると無地になる）
- ホーム一覧に定型文が出る。タイトル・カテゴリバッジ・本文プレビューが揃う
- ヘッダーにアクティブ環境名、設定・入出力・検索・追加の各アイコン
- カテゴリチップ行（並べ替え + All + 各カテゴリ）
- 無料プランなら画面下部にバナー広告（Proでは非表示）

よくある壊れ方:
- 読み込み画面から進まない → 初期化のラッチ（`useAppInitialization`）の退行
- アイコンが出ない → アセットの静的importが解決できていない

### タイトルのみコピー（v1.3.0の新機能）
確認:
- タイトル行の右端にグレーのコピーアイコン。タップで緑チェックへ変わり約2秒で戻る
- `sim.sh clipboard` がタイトル文字列のみを返す（改行も本文も付かない）
- タイトル未設定の定型文ではアイコンが出ず、タップしても何も起きない
- 使用頻度順の並べ替えで、タイトルコピーはカウントされない

### 本文コピー
確認:
- カード右下のコピーボタンで `sim.sh clipboard` が本文を返す
- 「タイトルもコピーする」がONの定型文では `タイトル + 改行 + 本文`

### カテゴリ絞り込み
確認:
- カテゴリチップをタップすると一覧が絞られる
- 別画面へ遷移して戻っても選択が維持される
- 選択中のカテゴリを設定から削除すると「All」へ自動で戻る

### プルリフレッシュ
確認: 一覧を下へ引くとインジケータが出て、**必ず戻る**（回りっぱなしにならない）

### 並べ替えメニュー
確認: 作成日・更新日・タイトル・使用頻度の4種が選べ、一覧の順序が変わる

### 編集・削除メニュー（定型文・ショートカット共通。検索画面も同じ）
確認:
- カード右上の「・・・」をタップすると、その真下に右端を揃えて「編集」（鉛筆アイコン）「削除」（ゴミ箱アイコン、赤）のメニューが出る
- 画面下端（広告バナー付近）のカードでは、メニューがボタンの上に出る
- メニューの外側をタップすると閉じ、下のカードは反応しない（Androidは戻る操作でも閉じる）
- 「編集」で編集画面が開く。「削除」で確認ダイアログが出て、キャンセルなら残る

よくある壊れ方:
- iOSで「編集」を選んでも編集画面が開かない → メニューのModalが閉じ切る前に遷移している（`useItemActionMenu` の `onDismiss` 待ちの退行）
- Androidでメニューがボタンからステータスバーの高さ分ずれる → edge-to-edge とModalの座標の食い違い

## 2. 検索（`app/search.tsx`）
到達: ホームの検索アイコン。検索対象はホームの表示対象（定型文／ショートカットの切替トグル）を引き継ぐ

確認（定型文・ショートカット共通）:
- 開いた直後、環境チップで**アクティブ環境が選択済み**になっている
- チップを切り替えると一覧が変わり、検索文字を変えても選択が維持される
- 検索語を入れると、一致のある環境だけがチップに残り件数が出る。選択中の環境に一致が無くても自動では切り替わらず、一覧は空状態になる
- 入力から約300msのデバウンス後に結果が更新される
- プルリフレッシュのインジケータが戻る

確認（定型文）:
- 検索語は未展開のタイトル・本文に対する部分一致（変数の展開結果は対象外）
- ここでもタイトルタップでタイトルのみコピーできる

確認（ショートカット）:
- アクティブ以外の環境だけに紐づけたショートカットが、その環境のチップを選ぶと見つかる
- カスタム変数を参照する値は、チップを切り替えると表示が変わり、値タップ後のクリップボードの実値も選んだ環境の値になる
- アクティブ以外の環境のショートカットを「・・・」メニューの「編集」で開くと、保存済みの名前・環境・値が入っている。保存してもショートカットの総数が増えず、戻ると一覧と件数に反映される
- 削除すると一覧と件数から即座に消える

よくある壊れ方: 開いた直後に環境が未選択、またはチップ選択が勝手に戻る（派生状態の退行）。アクティブ以外の環境のショートカットの編集画面が空で開き、保存すると重複して作成される（編集対象をアクティブ環境の一覧から探す退行）

## 7. 共通コンポーネント
- **モーダル**: 開閉アニメーションが滑らか。閉じた後に再度開ける（React Nativeの`Modal`を各画面で直接使用）
- **選択モーダル（カテゴリ / 対象環境）**: 確定で値が反映され、**キャンセルすると編集内容が破棄される**（再オープン時に前回の編集が残らない）
  ※ 日付・ホイール系のピッカーコンポーネントは持たない（`@react-native-community/datetimepicker` と `@react-native-picker/picker` は依存ごと削除済み）
- **ドロワー / 環境スイッチャー**: 環境を切り替えると一覧の変数展開結果が変わる
- **環境0件**: 環境セレクタを開いても落ちない
- **ダークモード**: 端末の外観設定を切り替えて、色が破綻しないこと

## 8. 自動化できない項目（実機で手動確認）

以下はシミュレータでは再現しないため、必ず実機のチェックリストとして残す。

- **拡張キーボード**（設定でのキーボード追加が必要。使用回数の記録にはフルアクセス許可も必要）
  - 「タイトルもコピーする」ON: タイトル行 + タイトル挿入ボタン + 区切り線が出る
  - タイトル挿入ボタンでは詳細画面が閉じない
  - 下部の挿入ボタンは**本文のみ**を挿入して閉じる
  - OFF: 従来と同じ本文開始位置
  - タイトルが空 + ON: プレースホルダー表示、挿入ボタンは非表示
  - 長い本文でスクロールした後に別の定型文を開いても、タイトル行が画面外に残らない
- **フルアクセスOFFでのキーボード挙動**（iOSサンドボックスの制約はシミュレータで再現しない）
  - 一覧表示・挿入・プロファイル切替・カテゴリ絞り込みが通常どおり動く
  - 並べ替えメニューに4種すべてが出る（使用頻度順も選べる）
  - 定型文を挿入しても使用回数が増えない
  - 設定画面に「使用頻度の記録: 無効」と許可手順が出る
  - フルアクセスをONにすると挿入で使用回数が増え、設定画面が「有効」に変わる
- **触覚フィードバック**（コピー時の Haptics.Light）
  - キーボードからの挿入時も振動するか。フルアクセスOFFでも振動するかを併せて確認する
- **課金の実購入フロー**（期間短縮の挙動を含む）
- **Android実機**（`RefreshControl` の実装がiOSと別。プルリフレッシュは両OSで確認）
